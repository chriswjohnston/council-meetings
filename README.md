# Nipissing Township Public Records
**nipissing.ca** — A civic transparency archive for Nipissing Township.

Not an official Township resource. Built and maintained independently.
Source documents sourced from [nipissingtownship.com](https://nipissingtownship.com).

---

## What This Site Does

This repository powers three public archives:

| Section | URL | What it tracks |
|---|---|---|
| Council Meetings | `/council` | Agendas, minutes, agenda packages, video recordings (2018–present) |
| By-Laws | `/bylaws` | Every by-law passed by council, with vote records |
| Resolutions | `/bylaws` | Every resolution passed by council, with mover/seconder |
| Boards & Committees | `/boards` | Recreation Committee, Museum Board, Cemetery Committee |

## Architecture

### Site Structure

```
docs/                          ← GitHub Pages root (served as nipissing.ca)
├── index.html                 ← Unified home page with search across all data
├── shared.css                 ← Design system (navy/teal/gold palette)
├── shared.js                  ← Data loading, search scoring, card renderers
├── council.html               ← Council meetings listing
├── meeting-detail.html        ← Individual meeting page
├── bylaws.html                ← By-laws & resolutions listing
├── bylaw-detail.html          ← Individual by-law page
├── resolution-detail.html     ← Individual resolution page
├── council-data.json          ← Master council meetings dataset
├── bylaws-data.json           ← Master by-laws dataset
├── resolutions-data.json      ← Master resolutions dataset
├── boards-data.json           ← Boards & committees dataset
├── boards/                    ← Board-specific pages
└── 2018/ … 2026/              ← Year pages (generated by scraper.py)
    └── {meeting-slug}/        ← Individual meeting pages
        └── files/             ← Downloaded PDFs
```

### Scrapers

Three independent scrapers run on separate schedules:

#### `scraper.py` — Council Meetings
- Scrapes [nipissingtownship.com/council-meeting-dates-agendas-minutes/](https://nipissingtownship.com/council-meeting-dates-agendas-minutes/) for new PDFs
- Fetches YouTube RSS for video recordings
- **Carry-forward strategy**: meetings from 2018–2023 are no longer on the live township site; the scraper preserves these from the existing `council-data.json` rather than rebuilding from scratch
- Generates HTML year pages (`docs/2018/` through `docs/2026/`)
- Writes `docs/council-data.json`
- State files: `state.json` (YouTube cache), `html_page_cache.json` (404 cache), `summaries.json` (AI summaries)

#### `scrape.py` — By-Laws & Resolutions
- Scrapes the by-laws listing page
- Parses council meeting minutes PDFs to extract every by-law and resolution with vote records
- Uses OCR (Tesseract) for scanned PDFs
- Generates AI summaries via Anthropic API
- Writes `docs/bylaws-data.json` and `docs/resolutions-data.json`

#### `scrape_boards.py` — Boards & Committees
- Scrapes Recreation Committee, Museum Board, and Cemetery Committee pages
- Tracks membership, meeting dates, and agendas
- Writes `docs/boards-data.json` and `docs/boards/` pages

## Scrape Schedule

| Workflow | Schedule | Notes |
|---|---|---|
| Council | Every Friday 5pm EST | Weekly catch-all |
| Council | Council meeting Tuesdays 7am EST | Runs day-of for each known 2026 meeting date |
| By-Laws | Every Friday 5pm EST | Offset by 1 hour from council |
| Boards | Every Friday 6pm EST | Runs after both scrapers complete |

Council meeting dates for 2026 are hardcoded in `scrape-council.yml`. Update this file each year with the new schedule from the Township.

| 2018–2021 | ✓ HTML (web pages) | Some (2021 onward) | — |
| 2022 | ✓ | ✓ (nipissingtownship.com) | ✓ |
| 2023 | ✓ | ✓ | — |
| 2024–2026 | ✓ | ✓ | ✓ |

2022 and earlier agenda packages link to nipissingtownship.com's wp-content uploads, which remain accessible even though the township's main council page no longer lists them.

## Key Design Decisions

**Carry-forward**: `scraper.py` loads `docs/council-data.json` at the start of every run. Any meeting already in that file but not found on the live township site is carried forward unchanged. This preserves 2022/2023 data permanently without needing a separate patch file.

**Separate scrapers**: Council, bylaws, and boards scrape completely different sources and can fail independently. Keeping them separate means a broken bylaw scraper doesn't stop council meetings from updating.

**Static site**: Everything is pre-generated JSON and HTML. No server, no database, no build step beyond the scrapers. GitHub Pages serves it directly.

**AI summaries**: When `ANTHROPIC_API_KEY` is set, `scraper.py` generates meeting summaries using Claude Haiku. Summaries are cached in `summaries.json` and never regenerated once created. The site is fully functional without summaries.

## Setup (New Repo)

1. Copy all files from this repo
2. Set `ANTHROPIC_API_KEY` in GitHub repo secrets (optional — only for AI summaries)
3. Update `docs/CNAME` to your domain
4. Enable GitHub Pages from Settings → Pages → Source: `docs/` folder
5. Run **Scrape Council Meetings** manually once to verify everything works
6. The scheduled workflows will keep everything updated automatically

---

## Files to Never Delete

- `state.json` — YouTube video cache. If deleted, scraper loses all previously matched videos.
- `summaries.json` — AI meeting summaries. Expensive to regenerate (API calls per meeting).
- `html_page_cache.json` — 404 cache for dead WordPress URLs. Prevents re-probing hundreds of dead links every run.
- `docs/council-data.json` — The master dataset. Contains all historical meeting data including 2022/2023 which is no longer on the live site.

---

## Updating Council Meeting Dates

At the start of each year, add the upcoming year's council meeting dates to:

1. `docs/council-data.json` — add entries with `null` URLs (they fill in automatically once published)
2. `.github/workflows/scrape-council.yml` — add cron entries for each meeting Tuesday
